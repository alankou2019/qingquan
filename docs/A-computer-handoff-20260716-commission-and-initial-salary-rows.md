# A电脑交接：提成月表和初始工资表员工行操作

## 本次功能

### 月提成核算

1. 提成月份改为月份选择框，按钮改为“生成此月提成核算表”。
2. 已存在核算表时直接提示并打开原表，不重复生成。
3. 已归档月份不再显示为可编辑核算表，提示到归档记录查看或恢复。
4. 每个员工行增加“编辑、删除”：
   - 编辑用于增加或减少该员工本月适配的提成项目。
   - 删除只从当前月提成核算表移除员工，不删除人事档案。
5. 保存整张核算表时保留员工单独调整后的项目，不会重新按规则覆盖；已删除员工也不会自动回来。
6. 员工删除后重新计算参与人数、匹配人数和提成合计。

### 初始工资表

1. 工资项目按以下顺序展示：应发总额、应发项目、应扣总额、应扣项目、实发总额、统计/数据/说明项目。
2. 应发、应扣、合计以及辅助类别使用不同浅色底色，便于横向核对。
3. 应发总额、应扣总额、实发总额为系统计算列，不保存为普通项目，也不改变固定项目名称。
4. 每个员工行增加“编辑、删除”：
   - 默认整行只读，点编辑后只开放可录入项目，公式和合计仍只读。
   - 保存只保存当前员工行。
   - 删除只将员工移出初始工资表，不影响人事档案、部门和历史工资/归档。
5. 已移出员工显示在表格下方，可以恢复到初始工资表，原基础工资数据仍保留。

## 安全与数据影响

1. 所有查询和修改都带企业 `company_id`，保持租户隔离。
2. 新增员工提成项目修改、员工删除、初始工资保存/移出/恢复操作日志。
3. 没有新增数据库表或字段，不需要执行数据库迁移。
4. 没有修改工资归档和提成归档快照，归档数据保持不可编辑。
5. 没有修改营运管理后台、生产配置或服务器文件。
