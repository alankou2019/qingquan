# 薪酬管理模块上线前验收清单

## 验收目标

本清单用于薪酬管理模块正式上线前的功能、权限、数据和安全检查。验收时只使用脱敏开发库或测试库，不使用生产客户工资表、生产配置、服务器密码或数据库密码。

## 一、基础环境检查

- [ ] 使用最新 GitHub 代码，确认没有未合并的 A/B 电脑开发提交。
- [ ] 本地或测试服务器 PHP、Phalcon、MySQL/MariaDB 可正常运行。
- [ ] 薪酬模块安装脚本已执行，薪酬相关数据表存在。
- [ ] 测试企业已开通薪酬管理模块。
- [ ] 测试企业按需要开通：
  - 工资表核算
  - 工资条发放
  - 提成核算
  - 绩效工资核算
- [ ] 不把测试工资表、上传文件、日志、生产配置提交到仓库。

## 二、营运后台验收

### 企业模块开通

- [ ] 营运后台可进入企业编辑页。
- [ ] 可为企业开通或关闭“薪酬管理”模块。
- [ ] 可分别选择工资表核算、工资条发放、提成核算、绩效工资核算。
- [ ] 关闭薪酬管理后，企业后台和员工端不展示薪酬入口。
- [ ] 只开通部分子功能时，企业后台菜单按开通项显示。

### 企业平台类型

- [ ] 新增或编辑企业时，可维护企业使用平台类型。
- [ ] 已支持钉钉、企业微信；飞书后续扩展时需纳入同一配置入口。
- [ ] 薪酬员工导入/同步页面读取同一企业平台配置，不单独重复维护。

## 三、企业后台验收

### 薪酬首页与菜单

- [ ] 企业后台左侧菜单展示“薪酬管理”。
- [ ] “工资项目设置”和“薪酬操作日志”在薪酬模块开通后可见。
- [ ] “工资表核算”“工资表归档记录”“薪酬统计报表”跟随“工资表核算”开通状态。
- [ ] “工资条发放”跟随“工资条发放”开通状态。
- [ ] 原有绩效考核页面仍可进入，不被薪酬菜单影响。

### 工资项目设置

- [ ] 可选择平台提供的通用工资项目。
- [ ] 可新增、编辑、删除企业自定义工资项目。
- [ ] 工资项目支持“数字”和“公式”属性。
- [ ] 数字项目可手工录入或通过 Excel 导入。
- [ ] 公式项目可按指定工资项目计算。
- [ ] 金额保留小数点后 2 位，按四舍五入处理。
- [ ] 企业第一次导入工资表且未设置工资项目时，可按导入表头生成工资项目。
- [ ] 初始工资表支持手工逐条录入，也支持 Excel 导入后再调整。

### 工资表核算

- [ ] 工资表核算页面以类似 Excel 的可编辑工资表呈现。
- [ ] 核算表项目来源于工资项目设置和初始工资表。
- [ ] 可从初始工资表生成指定月份工资表。
- [ ] 可编辑员工工资项目金额。
- [ ] 保存后金额合计正确，应发、扣款、实发计算正确。
- [ ] 提交审核前可继续修改。
- [ ] 提交审核后进入审核流程。
- [ ] 审核全部通过后，HR 才能执行“发工资条”和“归档”。
- [ ] 审核不通过时，工资表可回到核算修改流程。

### Excel 导入

- [ ] 工资表模板可正常下载。
- [ ] 导入匹配规则为优先按姓名匹配。
- [ ] 姓名重名时按手机号辅助匹配。
- [ ] 手机号匹配异常、姓名不存在、重名未能确认的数据进入异常列表。
- [ ] HR 可根据异常列表修正后重新导入。
- [ ] 异常数据不会直接进入正式工资表。
- [ ] 导入文件只在开发/测试环境使用，不提交仓库。

### 薪酬管理授权

- [ ] 可设置工资表审核人。
- [ ] 工资表提交审核后，需指定审核人全部同意。
- [ ] 可设置薪酬查询授权。
- [ ] 可授权查看部门薪酬。
- [ ] 可授权查看指定员工薪酬。
- [ ] 可单独勾选“允许导出薪酬数据”。
- [ ] 未授权账号无法查看非授权范围内薪酬数据。
- [ ] 无导出权限账号看不到导出入口，直接访问导出地址也被拦截。

### 工资条发放

- [ ] 工资表审核通过后，可从工资表核算页发工资条。
- [ ] 归档记录中的工资表可再次发工资条。
- [ ] 发工资条时提示发放范围：
  - 全部
  - 部门
  - 指定员工
- [ ] 后端再次校验员工范围，不能通过篡改参数发给非本工资表员工。
- [ ] 发放后工资条进入已发布状态。
- [ ] 工资条发放页面可查看发布记录。
- [ ] “查看确认”页面可查看员工查看和确认情况。
- [ ] “查看确认”页面可按全部、未查看、已查看未确认、已确认筛选。
- [ ] 有导出权限时可导出确认结果。
- [ ] 无导出权限时不能导出确认结果。

### 归档记录

- [ ] 审核通过后的工资表可归档。
- [ ] 归档后工资表进入归档记录模块。
- [ ] 归档记录中的工资表数据不可直接修改。
- [ ] 归档记录保留“发工资条”按钮。
- [ ] 归档记录保留“恢复”按钮。
- [ ] 恢复会把归档工资表数据重新导入工资表核算页面。
- [ ] 恢复后原归档记录仍保留。

### 薪酬统计报表

- [ ] 可按月份、部门、员工关键字查询。
- [ ] 超级管理员可查看本企业全部数据。
- [ ] 非超级管理员按薪酬查询授权查看。
- [ ] 无授权账号不展示薪酬明细。
- [ ] 有导出权限账号可导出当前筛选范围。
- [ ] 导出日志只记录动作和条数，不记录工资金额明细。

### 薪酬操作日志

- [ ] 工资项目保存、初始工资表保存、工资表导入、核算保存有日志。
- [ ] 提交审核、审核处理、发工资条、归档、恢复有日志。
- [ ] 薪酬授权保存有日志。
- [ ] 薪酬报表导出、工资条确认结果导出有日志。
- [ ] 员工端查看本人薪酬、确认工资条、查看下属薪酬有日志。
- [ ] 日志不记录工资金额、工资明细、生产密码、上传文件内容。

## 四、员工手机端验收

- [ ] 企业开通“薪酬管理 + 工资条发放”后，员工端展示薪酬入口。
- [ ] 未开通时员工端不展示薪酬入口，直接访问会提示未开通。
- [ ] 当月薪酬可查看已发给本人的当月工资条。
- [ ] 当年薪酬可查看本年度薪酬汇总。
- [ ] 往年薪酬可查看历史年度薪酬汇总。
- [ ] 下属薪酬只对已授权人员展示。
- [ ] 下属薪酬只能查看授权部门或指定员工范围。
- [ ] 查看下属薪酬不替员工本人标记“已查看”。
- [ ] 员工打开工资条详情后记录本人已查看。
- [ ] 员工点击确认后记录确认时间。

## 五、权限和数据隔离专项检查

- [ ] 所有薪酬查询都带当前企业 `company_id`。
- [ ] 通过 URL 修改工资表 ID、工资条 ID、归档 ID，不能访问其他企业数据。
- [ ] 非管理员查看薪酬报表时，只返回授权范围。
- [ ] 非管理员导出薪酬报表时，必须有导出授权。
- [ ] 工资条确认结果导出必须有导出授权。
- [ ] 员工手机端只能查看本人已发布工资条。
- [ ] 下属薪酬必须按薪酬查询授权控制。
- [ ] 操作日志按当前企业隔离。
- [ ] 不在日志中保存敏感明细。

## 六、旧功能回归检查

- [ ] 原企业后台绩效考核入口可正常打开。
- [ ] 原员工端考核模块可正常打开。
- [ ] 员工、部门、权限、积分相关旧页面未被薪酬菜单影响。
- [ ] 未开通薪酬模块的企业，旧功能使用路径不变化。

## 七、上线前建议

- [ ] 先找 1 家测试企业做完整流程试跑。
- [ ] 用 5 到 10 名测试员工模拟导入、核算、审核、发放、确认。
- [ ] 再用 1 个无权限账号、1 个部门授权账号、1 个指定员工授权账号测试权限。
- [ ] 测试通过后再安排生产升级，不直接在生产服务器上改代码。
- [ ] 上线当天保留旧代码备份和数据库备份。
- [ ] 上线后第一家客户先小范围试用，不一次性放开所有客户。
