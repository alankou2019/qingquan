# A电脑交接：薪酬员工编辑和删除

日期：2026-07-25

## 本次功能

- 在薪酬管理“员工同步/导入”页面的人员列表末尾增加“编辑”和“删除”操作。
- 编辑采用行内方式，可修改姓名、手机号、部门和岗位，保存后不跳转页面。
- 删除成功后直接移除当前人员行并更新人数，不跳转或刷新页面。
- 页面右上角改为“返回薪酬管理”，返回完整企业薪酬管理后台，不再只打开内容页。

## 安全和兼容处理

- 只有企业管理员可以编辑、删除本企业员工，接口按 `company_id` 强制隔离。
- 企业管理员、当前登录员工不能删除。
- 正在参与旧绩效考核的员工不能删除，避免影响已有考核流程。
- 删除员工不会删除已经形成的工资表、归档记录和工资条历史。
- 钉钉、企业微信等平台同步员工被删除后，下次组织同步时仍可能重新导入。
- 姓名、手机号、部门和岗位保存时均进行格式及企业范围校验，手机号在企业内不能重复。
- 编辑、删除均写入薪酬操作日志。
