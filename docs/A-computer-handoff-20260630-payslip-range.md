# A电脑交接说明：工资条按范围发放

提交日期：2026-06-30

## 本次完成内容

1. 工资表核算页的“发工资条”不再直接发放，改为进入“工资条发放确认”页。
2. 工资表归档记录页的“发工资条”不再直接发放，也改为进入同一个确认页。
3. 发放确认页支持三种范围：
   - 全部
   - 部门
   - 指定员工
4. 后台发放逻辑增加范围校验：
   - 选“部门”必须至少勾选一个部门。
   - 选“指定员工”必须至少勾选一个员工。
   - 后台会再次按工资表人员校验员工范围，避免提交非法员工 ID。
5. 归档记录入口会校验归档记录是否存在；即使原工资表曾恢复到核算表，仍可从归档记录入口进入发放确认。

   - 来源

   - 总人数
   - 已发工资条人数
   - 应发、扣款、实发合计

4. 本地测试数据中，归档工资表按“全部”发放成功，共发放 2 人；归档记录页已显示“已发 2 人”。

## A电脑继续开发前注意

1. 先同步 GitHub 最新代码，再继续开发。
2. 不要提交生产配置、密码、客户工资表、客户上传文件或日志。
3. 当前归档记录发放入口已经可用，但工资条详情仍主要关联现有工资表行数据；后续如果要做到“工资条详情完全按归档快照独立展示”，建议新增工资条快照字段或独立明细表。
4. 后续如继续开发“发放范围”增强，可以考虑增加：
   - 发放前预览选中人数和合计金额。
   - 已发人员二次发放提示。
   - 按部门/员工范围的发放日志。
