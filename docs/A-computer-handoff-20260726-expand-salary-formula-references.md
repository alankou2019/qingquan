# A 电脑交接：核算公式引用企业工资项目

日期：2026-07-26

## 本次功能

- 编辑或新增项目属性为“核算项”的工资项目时，核算公式区域显示本企业已启用的可计算工资项目。
- 可引用项目不再限制为“数据类”；应发类、应扣类和数据类的数字项目、核算项都可点击插入公式。
- 文本项目不列入公式引用，因为不能参与金额计算。
- 当前正在编辑的项目不列入引用，避免直接自引用。
- 应发总额、应扣总额、实发总额是系统固定汇总列，不在引用列表中，避免循环计算。

## 验证

- 本地编辑核算项项目 `id=39` 时，引用栏显示：基本工资、岗位工资、月固定加班费、缺勤扣款、全勤奖、社保补贴、社保扣款。
- 引用栏不显示应发总额、应扣总额、实发总额，也不显示当前正在编辑的项目。
