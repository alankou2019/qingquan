# A电脑交接说明：薪酬固定汇总项目

日期：2026-07-08

本次由 B 电脑完成，范围只涉及薪酬管理模块，不涉及营运后台，不涉及生产服务器。

## 本次功能

1. 工资项目设置增加系统固定项目：
   - 应发总额：所有应发类项目合计。
   - 应扣总额：所有应扣类项目合计。
   - 实发总额：应发总额 - 应扣总额。
2. 固定项目在工资项目设置页单独展示，不允许编辑、停用、删除。
3. 工资核算表中按更合理的位置展示固定汇总项：
   - 应发类项目后显示应发总额。
   - 应扣类项目后显示应扣总额。
   - 其他项目后显示实发总额。
4. 工资条、归档记录、薪酬报表、导入结果、员工确认明细等页面统一使用“应发总额 / 应扣总额 / 实发总额”文案。
5. 已启用工资项目的操作增加“删除”，同时保留“停用”：
   - 停用：只把项目状态改为停用。
   - 删除：软删除工资项目，不影响历史工资表和归档记录。
