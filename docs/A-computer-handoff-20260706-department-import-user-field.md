# A电脑交接：导入人员信息字段兼容修复

## 本次处理

- 修复导入人员信息时，开发库员工表没有 `jobnumber` 字段导致报错的问题。
- 旧逻辑写死用 `jobnumber` 保存和查重员工手机号。
- 新逻辑会自动识别员工表可用字段：
  - 优先 `jobnumber`
  - 其次 `mobile`
  - 再其次 `phone`
  - 如果都没有，则按“姓名 + 部门”判断是否重复，避免直接报错。
- 保存员工时只写入当前表真实存在的字段，避免脱敏开发库字段较少时再次报错。

## 本地验证

- `DepartmentController.php` PHP 语法检查通过。
- `/department/index` 页面冒烟测试返回 200。
- 未直接跑完整 Excel 导入，因为该导入会重建本地测试公司的部门和员工数据，可能影响当前人工测试数据。

## 注意事项

1. 生产旧库如果存在 `jobnumber` 字段，会继续走原手机号字段逻辑。
2. 脱敏开发库没有 `jobnumber` 字段时，不再报 “Column 'jobnumber' doesn't belong...”。
3. 如果后续继续测 Excel 导入，建议先用专门测试公司，避免覆盖正在测试的企业数据。
