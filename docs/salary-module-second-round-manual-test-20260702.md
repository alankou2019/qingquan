# 薪酬管理模块第二轮人工测试执行表

## 测试目的

本表用于薪酬管理模块上线前第二轮人工测试。测试只使用本地开发环境或测试环境，不使用生产数据库、生产配置、客户真实工资表、客户上传文件或服务器密码。

测试重点不是看页面能否打开，而是按 HR 的真实工作顺序确认：模块开通、工资项目设置、工资核算、审核、发工资条、归档、员工查看确认、查询导出、权限隔离、操作日志都能完整闭环。

## 测试环境

- 测试地址：`http://127.0.0.1:8101`
- 测试数据：脱敏开发库或测试库
- 测试企业：选择 1 家已开通薪酬管理的测试企业
- 测试员工：建议 5 到 10 人，至少包含 2 个部门、1 组重名员工、1 个主管或 HR 账号
- 测试前要求：先同步 GitHub 最新代码，不直接改生产服务器
