# A 电脑交接：初始工资表数字项全部复制

## 本次功能

- 初始工资表每个可手工录入的数字项表头下增加“全部复制”。
- 点击后弹出数字输入框，支持小数和负数，提交前统一按两位小数处理。
- 确认后把该工资项目的数值填入所有当前初始工资表员工，并提交保存整张初始工资表。
- 文本项、核算项、应发/应扣/实发系统合计项不显示“全部复制”。
- 不改变工资项目设置，也不修改已经归档的工资表数据。

## 主要文件

- `app/design/frontend/default/Salary/salary/project.volt`

## 保存与权限

- 批量操作沿用现有 `saveinitialsalary` 接口和当前登录企业会话。
- 没有新增企业 ID、员工 ID 或数据库连接参数等前端输入。
- 用户取消确认时不提交；确认后才保存所有员工的初始工资数据。
