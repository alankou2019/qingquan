# A 电脑交接：初始工资表和工资核算表直接编辑

日期：2026-07-26

## 本次流程调整

- 初始工资表取消每行“编辑、保存、取消”。
- 工资核算表取消每行“编辑、保存、取消”。
- 普通数字项和文本项打开页面后可以直接填写、修改。
- 核算项、应发总额、应扣总额、实发总额继续保持只读。
- 修改普通数字项后，公式及三项合计即时重新计算。
- 修改后统一使用表格下方的“保存整张工资表”。
- 每行“删除”保留，删除范围和原有数据隔离规则不变。
- 已归档或其他不可编辑状态的工资表继续保持只读。
