# A 电脑交接：工资核算表数据类项目导入

日期：2026-07-26

## 本次功能

- 工资核算表生成后，在状态栏增加“数据模板下载”和“导入数据”。
- 下载模板自动带出当前工资核算表员工的手机号、姓名，以及当前月份快照中的数据类工资项目。
- Excel 只更新当前月份工资核算表的数据类项目，不修改初始工资表和归档记录。
- 支持多次导入；同一员工同一项目重复导入时，以最后一次导入的非空值为准。
- 空白单元格不覆盖原数据；明确填写 `0` 时会覆盖原数据。
- 导入后复用工资核算保存逻辑，重新计算核算项、应发总额、应扣总额和实发总额。

## 人员和项目匹配

- Excel 必须包含“手机号”和“姓名”两列。
- 首先按手机号匹配当前月份工资核算表员工。
- 一个手机号只对应一名员工时直接匹配；同一手机号对应多人时，再按姓名精确匹配。
- 手机号或姓名为空、手机号不存在、重号后姓名不能唯一匹配时，该行不写入并进入异常列表。
- Excel 表头不是当前工资核算表数据类项目时跳过，并在异常列表中说明。
- 数字项目内容不是有效数字时，该单元格不写入并在异常列表中说明。

## 页面行为

- 文件通过 AJAX 上传，导入后直接刷新当前工资核算表区域，不跳转到系统提示页。
- 当前页显示更新单元格数、涉及员工数、跳过空白数和异常明细。
- 当前表有未保存修改时禁止导入，避免覆盖 HR 尚未保存的数据。
- 上传的临时 Excel 文件处理完成后立即删除。

## 本地验证

- PHP 7.3 语法检查通过。
- 模板下载可生成包含 7 名当前员工和 2 个数据类项目的 Excel。
- 首次导入同时写入两个项目成功。
- 第二次导入仅填写一个项目：已填写项目更新，空白项目保留原值。
- 第三次导入填写 `0`：原值被正确覆盖为 `0.00`。
- 不存在的手机号进入异常列表，其他正确行仍然导入。
- 全部项目为空时不写入，提示“空白单元格不会覆盖原数据”。
- 页面实际上传后在当前页显示导入结果。
- 验证结束后已把本地测试值恢复为原来的 `0.00`。
