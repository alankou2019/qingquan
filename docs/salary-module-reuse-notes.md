# 薪酬管理模块交接包复用说明

本次在旧版考核系统中按小步方式接入薪酬管理基础能力，没有引入交接包中的 Webman、Vue3、uni-app 新平台代码。

已复用的内容：

- 薪酬项目设计：固定项目、核算项目、应发、应扣、计入实发等规则。
- 数据表设计思路：工资项目、员工工资结构、月度工资表、工资明细快照、工资条签收记录。
- 通用工资项目模板：基本工资、岗位工资、绩效工资、提成、社保、公积金、个税等。
- 工资条状态思路：待发布、查看、签收、异议等后续流程预留字段。

本次已落地：

- 新增旧系统 `Salary` 模块。
- 新增薪酬相关数据表安装脚本，使用旧系统表前缀机制。
- 新增后台“薪酬管理 / 工资项目”菜单。
- 新增后台工资项目列表、新增、编辑、删除和按企业初始化通用工资项目。

暂未直接接入：

- 交接包中的 Vue 后台页面。
- 交接包中的 uni-app 小程序页面。
- Webman 后端接口。
- 完整月度工资核算、审批、发布、工资条签收流程页面。

后续建议：

1. 先在测试库执行旧系统开发环境自动安装，确认薪酬表和菜单正常生成。
2. 选一家测试企业初始化通用工资项目。
3. 再继续做员工工资结构配置。
4. 最后做月度工资核算、审批发布、工资条签收和导出。

安全边界：

- 不提交生产数据库、生产配置、服务器密码、客户数据。
- 薪酬数据必须始终带 `company_id`，后续页面和接口都要按企业隔离。
- 工资条和工资核算后续上线前必须补操作日志和权限校验。
