# A 电脑交接：通用工资项目启用与初始工资表两行显示

## 本次功能

- 工资项目设置的“通用项目”不再提供删除操作，保留“编辑”。
- 未启用的通用项目显示“启用”；启用后纳入当前企业的“企业工资项目”。
- 已启用的通用项目在上方显示“已启用”，可在企业工资项目中停用。
- 企业编辑过的通用项目再次启用时保留企业自己的名称、类别、属性、公式和默认值。
- 初始工资表的员工、手机号、部门和工资项目标题使用稳定列宽，文字最多显示两行，不再逐字竖排；完整内容可通过鼠标悬停查看。

- `app/code/Salary/Model/SalaryProjectModel.php`

## 数据与安全

- 启用接口只接受 POST 请求。
- 企业 ID 继续从当前登录会话读取，不接受前端传入企业 ID。
- 启用时只处理当前企业和指定平台通用项目，不影响其他企业。
- 启用动作写入薪酬操作日志 `project_template_enable`。
- 工资项目的启用、停用或编辑不修改已经归档的历史工资表数据。
