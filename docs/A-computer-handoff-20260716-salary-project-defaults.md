# A电脑交接：工资项目编辑和初始默认值

## 本次功能

1. 工资项目编辑区统一改为“编辑工资项目”。
2. 自定义项目、已启用或未启用的通用项目都可以编辑。
3. 通用项目列表增加“编辑、删除”，删除只影响当前企业，不修改平台模板和其他企业。
4. 数字项可设置默认数字，文本项可设置默认文本；切换项目属性时只显示对应输入框。
5. 初始工资表中，员工尚未保存该项目数据时使用项目默认值；员工已有单独数据时保留员工数据，不被默认值覆盖。
6. 项目默认值和后续编辑只影响当前配置及未保存的初始数据，不修改工资归档快照。
7. 固定汇总项目仍由系统维护，本次没有增加编辑、删除入口。

## 数据库升级

- Salary 模块版本：`1.0.0.13`。
- 新增迁移：`app/code/Salary/sql/install-1.0.0.13.php`。
- `salary_projects` 新增：
  - `default_number decimal(14,2)`
  - `default_text varchar(500)`
- 旧版取消勾选通用项目时曾写入 `deleted_at`，迁移会将这些记录恢复为未启用状态，便于继续编辑。

## 已验证

- PHP 7.3 语法检查通过，代码保持 PHP 5.6 可用语法。
- 通用项目未启用时也可编辑，企业修改内容可保存。
- 通用项目删除采用当前企业软删除，企业之间隔离。
- 数字默认值按两位小数四舍五入；文本默认值能显示在初始工资表。
- 员工已有个性值时优先显示个性值，不被项目默认值覆盖。
- 修改工资项目之前和之后，工资归档快照哈希一致。
- 本地入口及工资项目页返回 HTTP 200。

## A电脑注意

1. 开发前先同步本提交，不要手工复制覆盖项目目录。
2. 首次打开系统时让 Salary 模块升级程序执行 `1.0.0.13` 迁移。
3. 本次只修改薪酬模块，没有修改营运管理后台。
4. 如果 A 电脑准备修改工资项目、初始工资表或 SalaryController，请先看本交接和本提交，避免覆盖默认值与企业隔离逻辑。
5. 不包含生产配置、客户数据和服务器凭证；不要直接部署生产，须先完成开发/测试环境人工测试。
