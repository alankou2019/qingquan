# A 电脑交接：初始工资表即时合计与整表保存

## 本次功能

- 自定义工资项目只显示“编辑、删除”，不再显示“停用”。
- 平台通用项目继续显示“编辑、停用”，停用后可从通用项目列表重新启用。
- 服务端同时限制自定义项目停用接口，避免绕过页面直接停用。
- 初始工资表编辑数字项时，即时重新计算核算项、应发总额、应扣总额和实发总额。
- 初始工资表增加“保存整张工资表”和“清空当前数据”。
- 清空操作只修改当前页面：数字项变为 `0.00`，文本项清空；点击“保存整张工资表”后才写入数据库。
- “全部复制”改为只批量填写当前页面，统一由“保存整张工资表”保存。
- 页面存在未保存数据时显示提示，离开页面前浏览器会提醒。

## 计算规则

- 浏览器即时计算按工资项目顺序执行公式，并统一显示两位小数。
- 应发、应扣合计按项目的 `include_earning`、`include_deduction` 标记计算，与月工资核算逻辑保持一致。
- 保存时服务端仍会重新计算核算项，浏览器结果不是唯一可信来源。
