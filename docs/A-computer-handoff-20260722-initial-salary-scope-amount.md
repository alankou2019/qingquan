# A电脑交接：初始工资表范围设置金额与无刷新行保存

## 本次范围

本次只修改企业薪酬模块的“工资项目设置/初始工资表”，不修改营运后台、数据库结构、归档工资表和生产服务器。

## 已完成内容

1. 新增或编辑核算项时，公式候选只读取当前企业最新、已启用、未删除的“数据类”工资项目，排除文本项和当前正在编辑的项目。
2. 初始工资表单行“保存”改为 AJAX：保存后停留在当前页面和当前滚动位置，不刷新、不跳转。
3. 单行保存成功后只锁定当前行并显示结果；其他行尚未保存的修改仍保留，页面继续提示“当前数据尚未保存”。
4. 表头“全部复制”改为“设置金额”，支持以下范围：
   - 全部员工
   - 指定部门
   - 指定岗位
   - 指定员工（可多选）
5. 设置金额只对数字项开放，不对文本项、核算项和系统合计项开放。
6. 设置后立即重算员工的核算项、应发总额、应扣总额和实发总额；本次操作只更新当前页面，仍需点击“保存整张工资表”后才写入数据库。
7. 工资项目最新设置只影响初始工资表和以后新生成的核算表，不修改已生成的核算表及已归档快照。

## A电脑操作要求

1. 同步后打开 `/salary/project`，使用 `Ctrl+F5` 强制刷新。
2. 分别测试全部、部门、岗位、指定员工四种设置金额范围，并点击“保存整张工资表”后重新进入核对数据。
3. 同时编辑两行，只保存其中一行，确认另一行的未保存数据仍保留。
4. 新增一个启用的数据类项目，再编辑核算项，确认公式候选中只出现该企业的数据类项目。
5. 检查已归档工资表的人员、项目和金额没有随当前工资项目设置变化。
6. 用户完成手工测试并明确批准前，不得部署或覆盖生产环境。
