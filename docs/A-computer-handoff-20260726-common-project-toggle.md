# A 电脑交接：通用工资项目启用/停用联动

日期：2026-07-26

## 本次功能

- 通用项目未启用时显示“编辑、启用”。
- 点击“启用”后不跳转页面：
  - 通用项目状态立即变为“已启用”；
  - 操作按钮立即变为“编辑、停用”；
  - 对应项目立即加入“企业工资项目”。
- 已启用的通用项目可以在通用项目列表或企业工资项目列表点击“停用”。
- 点击“停用”后不跳转页面：
  - 对应项目立即从“企业工资项目”移除；
  - 通用项目状态立即变为“未启用”；
  - 操作按钮立即恢复为“编辑、启用”。
- 停用只改变当前企业项目的当前启用状态，不删除工资归档和历史工资表数据。
