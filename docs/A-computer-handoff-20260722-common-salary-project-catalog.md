# A电脑交接：平台通用工资项目目录调整

## 本次范围

只调整薪酬管理模块的平台通用工资项目目录，不修改营运后台、生产配置和历史工资归档数据。

## 调整内容

1. 从通用项目选择列表下架：
   - 固定补贴（`fixed_allowance`）
   - 固定扣款（本地企业曾编辑显示为“忠诚履约金”，编码 `fixed_deduction`）
   - 名称或编码为 `TEMP_COMMON_*`、`temp_default_*` 的测试模板
2. 平台默认名称调整：
   - 提成 -> 提成奖
   - 奖金 -> 绩效奖
   - 请假扣款 -> 缺勤扣款
   - 个税 -> 个人所得税
3. 企业项目只有仍使用旧默认名称时才随平台改名；企业自行修改过的名称不会被覆盖。
4. 已启用企业项目不强制删除，避免影响正在使用的初始工资表和月工资核算。
5. 已生成月工资表和归档记录使用自身快照，不受本次目录调整影响。

## 数据库升级

- Salary模块版本：`1.0.0.15`
- 升级脚本：`app/code/Salary/sql/install-1.0.0.15.php`
- 只更新模板状态和名称，不删除工资、工资条或归档记录。

## A电脑操作要求

1. 同步代码后只在独立测试环境执行升级。
2. 打开 `/salary/project`，确认通用项目列表已下架四类项目并显示四个新名称。
3. 检查已有企业自定义名称未被覆盖，已归档工资表内容保持不变。
4. 用户完成人工测试并明确批准前，不得部署生产环境。
