# A电脑交接：工资核算生成、直接归档与归档发工资条

## 本次范围

- 仅修改薪酬管理模块，未修改营运后台、生产配置和生产数据。
- 工资核算页月份操作由“查看”改为“生成”。生成时复制当时初始工资表的人员、工资项目和数据，形成独立月份快照。
- 工资核算表复用初始工资表交互：项目分类颜色、两行表头、单行编辑和无刷新保存、无刷新删除、即时公式及应发/应扣/实发计算、按全部/部门/岗位/指定员工设置金额、整表保存、清空当前数据。
- 工资核算页移除“提交审核”和“发工资条”，增加“导出Excel”和“归档”。工资表可直接归档；需要领导复核时由HR先导出Excel。
- 薪酬管理授权页不再显示工资审核人设置，只保留薪酬查询授权。旧审核表、接口和历史数据未删除，兼容旧记录。
- 归档记录操作增加“查看”，并保留“发工资条”和“恢复”。新增归档快照只读查看页。

## 兼容与隔离

- 已归档月份不能从初始工资表直接重新生成，页面提示先在归档记录中恢复。
- 草稿、已核算、已驳回、旧审核中、旧审核通过状态均可按新流程归档，避免历史工资表卡住。
- 初始工资表、月份核算表、归档表仍是三份独立数据；初始表后续变化不影响已生成或已归档快照。
- 恢复归档仍保留原归档记录，并把归档快照恢复到对应月份核算表。
