# B电脑开发交接说明 - 2026-06-29

## 当前代码位置

- 旧版考核系统生产代码目录：`v1/`
- 不建议从旧的 `src/` 目录直接开始薪酬模块开发，除非确认它就是当前运行版本。
- 开发前先拉取最新仓库代码，再新建薪酬管理开发分支。

## 本次已入库/待入库功能范围

- 企业后台评分人本人重置评分，归档前可重新评分。
- 管理后台保留整张考核表重置功能。
- 评分人端“参与评分”和“已评分”列表按提交状态区分。
- “已评分”列表显示进行中考核表的当前总分。
- 加分项只允许 0 或正数，减分项只允许 0 或负数。
- 归档历史的总分、详情页指标名称/类型、导出文件字段修复。
- 运营后台新增企业入口：添加钉钉公司、添加企业微信公司、添加飞书公司（飞书入口暂不开发）。
- 新增企业微信自建应用配置、免登录、通讯录同步、消息/事件回调相关代码。

## 开发注意事项

- 不要提交 `v1/app/etc/config.xml`，里面包含服务器数据库和企业微信敏感配置。
- 企业微信相关运行配置已在服务器生产环境配置完成，本地开发需要使用自己的测试配置。
- 企业微信新增表为 `scsx_platform_*`，薪酬模块不要复用这些表，薪酬应单独建表。
- 薪酬管理属于敏感数据模块，开发时要单独考虑权限、操作日志、历史记录和导出控制。
- 不要改动钉钉、微信公众号、企业微信现有入口的登录规则，除非有明确需求。

## 建议开发流程

1. 拉取最新仓库代码。
2. 新建分支，例如 `salary-module`。
3. 先做薪酬模块的数据表和菜单权限设计。
4. 再做后台页面和计算流程。
5. 最后接员工端查看、确认、工资条等功能。

## 上线前必须回归

- 钉钉企业登录、通讯录同步、评分、通知。
- 微信公众号网页登录、密码登录、评分流程。
- 企业微信工作台免登录、通讯录同步、评分、重置、通知。
- 考核表归档、详情、导出。
