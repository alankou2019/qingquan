# A 电脑交接：通用工资项目无跳转启用

## 本次功能

- 通用项目点击“启用”后通过后台异步请求处理，不再进入系统提示页面。
- 启用成功后，当前行状态立即显示“已启用”，“启用”按钮消失。
- 下方“企业工资项目”表格立即增加该通用项目，不需要刷新页面。
- 启用失败时在当前页面显示错误提示。
- 保留旧的同步 POST 行为，直接访问接口或旧浏览器提交时仍可正常工作。

## 主要文件

- `app/code/Salary/controllers/Frontend/SalaryController.php`
- `app/design/frontend/default/Salary/salary/project.volt`

## 安全与数据

- 异步接口仍使用当前登录企业会话，不接受前端传入企业 ID。
- 启用动作继续写入薪酬操作日志。
- 只修改当前企业通用工资项目状态，不影响其他企业和已归档工资数据。
