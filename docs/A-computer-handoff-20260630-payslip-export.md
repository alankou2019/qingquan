# A电脑交接说明：工资条查看确认导出

提交日期：2026-06-30

## 本次完成内容

1. 在“工资条发放 -> 查看确认”页增加“导出确认结果”区域。
2. 导出范围支持：
   - 全部
   - 部门
   - 指定员工
3. 导出会叠加当前确认状态筛选：
   - 全部
   - 未查看
   - 已查看未确认
   - 已确认
4. 导出 Excel 字段：
   - 工资月份
   - 员工姓名
   - 手机号
   - 部门
   - 应发
   - 扣款
   - 实发
   - 发放时间
   - 查看时间
   - 确认时间
   - 确认状态
5. 后台导出仍按公司和工资表校验，只导出当前企业当前工资表的数据。
